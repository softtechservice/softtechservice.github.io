🕹️ How to Play

Master the mechanics and conquer the 3D number-merge paths

01

Draw & Connect

Swipe to draw a path connecting grid tiles with matching numbers. Paths can turn in any cardinal direction to reach your targets.

02

Merge & Grow

Connect multiple tiles in a single continuous line to merge them into a new, higher-value tile. Bigger chains reward larger bonuses!

03

Master the Grid

Plan your drawing paths carefully. Crossing existing paths is blocked, so spacing and path-planning are key to solving complex boards.

04

Reach the Target

Complete specific level objectives or challenge yourself in Endless Mode to hit the legendary 2048 tile and post high scores.

⚙️ Architecture & Technology

Bridging native performance with advanced web engine capabilities

Flutter Container

Native mobile container providing hardware acceleration, platform bar UI matching, and API bridges.

BabylonJS WebGL

A high-performance 3D engine handling smooth tile movement, lighting, camera control, and particles.

Progress Persistence

Level stars, high scores, earned shop coins, unlocked avatars, and achievements saved to local database storage.

Sound & Haptic Link

WebAudio API effects integrated alongside Flutter bridges to support native device vibration channels.

Hybrid Architecture

Leverages high-performance WebGL canvas rendering inside a native shell using `flutter_inappwebview` for high frame rates and modular delivery.

Dynamic Theme Matching

Android and iOS status bars and navigation UI color parameters adaptively sync with selected in-game themes (Classic, Neon, Galaxy, Cyberpunk).

Performance Optimizations

Features dynamically scaled viewport resolutions, automated game loop pauses during menu overlays, and reduced particle density on entry-level mobile devices.
